# Window 3 数据库治理

## 模块职责

- `DatabaseWindow.tsx`：聚类列表页与入口态编排。
- `components/ClusterDetailWindow.tsx`：聚类详情、文件上传、文件操作。
- `components/FilePreviewModal.tsx`：文件预览弹窗。

## 开发规则

1. 列表态与详情态状态边界清晰，避免双向隐式改写。
2. 文件上传、删除流程明确 optimistic 与回写策略。
3. 接口失败必须有可读反馈，不得静默失败。
4. 新文件类型和批量操作要复用已有流程，而不是散写分支。

## 常见错题

### 错题 1：上传成功只改 UI 不回写

正确做法：明确乐观更新和服务端确认后的回写；失败时回滚并提示。

### 错题 2：删除失败静默

正确做法：展示用户能理解的失败文案，并保持数据不进入半删除状态。

### 错题 3：新增文件类型写死多处分支

正确做法：抽类型映射和预览策略，减少散落条件判断。

## 扩展性审查

- 增加文件类型是否无需改多处分支。
- 增加批量操作是否复用现有流程。
- 数据拉取策略是否能承载更大文件量与并发操作。
