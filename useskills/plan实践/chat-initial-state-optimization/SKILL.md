# 交互对话初始态优化

## 适用场景

当交互对话页面新建会话或首次进入时，空状态指向不明确，需要让用户知道从哪里开始提问时使用。

## 目标效果

删除本地和全局空状态中的旋转圆圈。初始态显示蓝色醒目提示语和居中输入框；发送问题后输入框平滑下移到原底部位置，宽度变长，圆角从小圆角变为原胶囊样式，再进入原有气泡生成流程。

## 设计约束

- 不改动原本满意的输入框样式、气泡样式、信息流呈现方式。
- 只在发送操作之前增加初始态和过渡动画。
- 提示语使用 DingTalk JinBuTi，颜色使用醒目蓝 `#4300FF`。
- 文本呈现可参考 SplitText 字符入场，但需用当前项目 React 和 GSAP 实现。
- 输入框初始宽度略短、矩形微小圆角；下移后恢复原胶囊样式。

## 时间轴建议

1. 空会话初始态：提示语字符入场，输入框居中。
2. 首次发送：锁定发送按钮，提示语淡出。
3. 输入框下移：同时执行 y 位移、宽度伸长、圆角变形。
4. 动画结束：输入框落在原底部位置。
5. 后续流程：开始原有 user 气泡、typing、bot 生成逻辑。

## 必查场景

- 新建对话。
- 本地切全局、全局切本地。
- 从其他窗口切回。
- 刷新或重新打开项目。
- 输入内容清空后宽度是否恢复。

## 常见错题

### 错题 1：为了初始态重写整个聊天组件

正确做法：保留原消息生成和气泡逻辑，只把首次发送前的状态和动画插入前置段。

### 错题 2：把 Vue 示例照搬进 React 项目

正确做法：借鉴动效形态，不照搬 Vue 代码；使用项目现有 React、GSAP、清理模式。

### 错题 3：不定义初始态恢复规则

正确做法：明确新建会话、模式切换、窗口返回时何时回到居中输入框。
