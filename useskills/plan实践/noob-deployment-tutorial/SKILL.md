# 新手部署教程

## 适用场景

当用户需要一份面向“只会下载 ZIP、不会命令行”的部署教程，或需要检查教程是否足够可执行时使用。

## 目标效果

产出一份中文教程，让新手能从下载 ZIP 开始，按路线 A、B、C 逐步跑起项目，并能根据报错定位原因和修复方式。

## 三条路线

- 路线 A：纯前端演示，最低门槛，只需 Node.js、pnpm、前端启动。
- 路线 B：前端 + PostgreSQL，增加聊天历史和数据库能力。
- 路线 C：Python 联邦/后端联调，启动中心服务和节点服务，验证全局检索。

## 写作规则

1. 每一步写清在哪个文件夹执行、输入什么、预期看到什么、失败怎么办。
2. 所有命令优先给 PowerShell 版本。
3. 先教最小成功闭环，再教增强能力。
4. 危险步骤单独提示，例如环境变量、数据库密码、清理缓存。
5. 缺失大文件和未上传目录要区分必须与可选。

## 必含章节

- 成功标准。
- 三条路线选择表。
- Windows 基础准备。
- Node.js、pnpm、PostgreSQL、Python 安装与验证。
- `.env` 场景化配置。
- 常见报错一键对照。
- 关闭、重启、二次进入、清理缓存。
