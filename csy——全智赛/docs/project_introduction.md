# AI Agent 安全评估平台 — 项目简介

## 项目背景

随着大语言模型（LLM）驱动的智能 Agent 在企业中广泛部署，一类新型安全威胁正在浮现：**间接提示注入（Indirect Prompt Injection, IPI）**。攻击者将恶意指令隐藏在网页、邮件或文档中，当 AI Agent 浏览这些内容时，会被"注入"指令，执行非预期操作——如转发敏感邮件、写入恶意记忆、泄露用户隐私。这类攻击不同于传统的网络安全威胁，因为它利用了 LLM 对自然语言的理解能力本身作为攻击面。

## 项目目标

构建一个**面向企业级 AI Agent 的安全评估平台**，能够：

1. **系统性检测** AI Agent 面临的安全风险（提示注入、记忆投毒、隐私泄露、越权操作）
2. **量化评估** Agent 的安全防御能力（评分 + 风险路径可视化）
3. **自动化渗透测试**（自适应红队自动变异攻击、发现防御盲区）
4. **提供防御方案**（8 层纵深防御体系，可插拔集成到任意 Agent）

## 技术方案

### 核心架构

```
用户接入 Agent → 自动生成攻击图 → 沙箱化执行 98 条安全测试 → 三 Agent 对比评估 → 量化报告
                                                    ↕
                                          自适应红队 (自动变异 + 反馈迭代)
```

### 三层 Agent 对比评估

| Agent | 定位 | 作用 |
|-------|------|------|
| CorpMate (规则引擎) | 传统方案基准线 | 展示关键词匹配的局限性 |
| Bare LLM (无防御) | 脆弱性对照 | 展示 LLM 在无防护下的安全风险 |
| Defended LLM (8层防御) | **核心交付物** | 验证纵深防御体系的有效性 |

### 8 层纵深防御体系

| 层 | 名称 | 防御内容 |
|----|------|---------|
| D1 | InputFilter | 输入过滤：27种注入模式检测、Unicode归一化、Base64解码、零宽字符剥离 |
| D2 | OutputFilter | 输出过滤：可疑收件人拦截、页面内容外泄检测、恶意记忆写入阻止 |
| D3 | Confirmation | 确认门控：危险操作（如发送邮件）需用户二次确认 |
| D4 | InstructionIsolation | 指令隔离：系统提示中严格区分可信/不可信数据来源 |
| D5 | ChainDetector | 链检测：识别"浏览网页→写入记忆→发送邮件"等可疑因果链 |
| D6 | IntentClassifier | 意图分类：区分用户真实意图与网页注入的伪指令 |
| D7 | MemoryAuditor | 记忆审计：阻止将可疑指令写入 Agent 持久记忆 |
| D8 | SessionMonitor | 会话监控：检测跨会话的记忆投毒攻击 |

### 4 大风险模式覆盖

| 模式 | 说明 | 测试用例 |
|------|------|---------|
| R1 - 间接提示注入 | 恶意网页/邮件中隐藏指令，Agent 浏览后执行 | 20 条 |
| R2 - 记忆投毒 | 恶意指令写入持久记忆，未来被检索执行 | 17 条 |
| R3 - 隐私泄露 | Agent 将敏感数据发送到外部 | 16 条 |
| R4 - 持久化 IPI | 完整 5 节点攻击链：网页→Agent→记忆→Agent→邮件 | 45 条 |

### 自适应红队

自动化渗透测试引擎，通过 5 种变异策略（编码绕过、同义词替换、跨会话拆分、社交工程、中英混用）对现有攻击进行变异，并利用防御反馈循环自适应调整攻击策略权重，持续发现防御盲区。

## 核心成果

| 指标 | 数据 |
|------|------|
| 安全测试用例 | 98 条 (覆盖 4 大风险模式) |
| 防御层 | 8 层纵深防御 |
| 单元测试 | 346 个 (全部通过) |
| Defended LLM 拦截率 | **100%** (98/98 全部 PASS) |
| Bare LLM 脆弱性 | 大量 FAIL (证明无防御的 LLM 极易被攻破) |
| 自适应红队 | 5 种变异策略, 迭代反馈, 自动报告 |

## 技术亮点

1. **契约驱动开发** — 前后端通过 JSON Schema 契约解耦，所有数据模型有唯一事实来源
2. **沙箱化执行** — Agent 在隔离沙箱中运行，工具调用被完整记录和审计
3. **HMAC 金丝雀机制** — 在攻击载荷中嵌入密码学指纹，追踪载荷在系统中的流转路径
4. **攻击图分析** — 基于 NetworkX 的图算法自动发现风险路径 (BFS/DFS, max_depth=4)
5. **实时 SSE 推送** — 评估过程事件流实时推送到前端，支持进度可视化
6. **三 Agent 对比** — 同条件对比评估，用数据证明防御有效性

## 应用场景

- **企业 AI Agent 上线前安全评估** — 接入 Agent，运行 98 条测试，生成安全评分报告
- **持续安全监控** — 定期运行红队测试，发现防御退化或新型攻击
- **安全防御方案选型** — 三 Agent 对比帮助企业选择合适的防御策略
- **安全研究与教育** — 98 条真实攻击场景 + 8 层防御实现，可供安全研究和教学使用
