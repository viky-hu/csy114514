- `app/layout.tsx`: root HTML shell and global style imports.
- `app/page.tsx`: initial login entry screen and same-route switch into the main workspace after the local Agent loading flow completes.
- `app/api/**/route.ts`: BFF layer for frontend-to-server boundaries.
- `app/windows/login/LoginIntroWindow.tsx`: Window 1 login surface copied from `C:\Users\Admin\final-main\final-main`, including the viewport-pinned SVG root, mouse-following band, inverted text overlay, auth-state CTA copy, CTA animation, Escape close behavior, mock sign-in close flow, login-gated scroll band expansion with top-position pointer unlock and first-scroll preservation of the current band width, plus the fixed second-page Agent entry prompt, local draft overlay, and locked mock loading state after either Agent action. - `app/windows/login/login-band-motion-controller.ts` and `login-band-motion-controller.test.ts`: login-window-private GSAP motion ownership boundary and focused Node tests. - `app/windows/login/AgentConnectDraft.tsx`: Second-page Agent Manifest configuration draft. It collects only fields backed by the frozen backend `AgentManifest`, shows a security/profile precheck, and keeps JSON details collapsed without exposing adapter-only endpoint/template inputs before that contract is frozen.
- `app/windows/main/MainWindow.tsx`: Main workspace SVG shell entered after the Agent loading overlay fades out. It starts from a full-screen blue SVG cover, then uses a GSAP timeline to collapse it into a horizontal separator line and reveal real SVG white top/main surface rectangles for later workspace content. It also owns the SVG-aware left navigation placement, tightened sidebar width boundary, default dashboard selection, content-region replacement, page fade-out/fade-in swapping, and intro timing for the main workspace; interrupted or completed motion restores the content region and keyed page shell to a visible, interactive steady state. The content region is intentionally close to the sidebar menu body while retaining larger right/bottom safety insets at 100% browser zoom.
- `app/windows/main/settings/**`: Focused Account Center/设置 content for the main workspace. `AccountSettingsWorkspace` owns profile loading, display-name dirty state, two-step avatar selection/crop/save state, password-dialog visibility, and local logout cleanup; `AccountAvatarCropDialog` uses `react-easy-crop@5.5.4` for constrained 1:1 drag/zoom interaction, while `avatar-image.ts` owns bounded Canvas rendering, the debounced 256px preview, and the 512px PNG upload file. The browser supplies its bearer token only to these same-origin routes; the upstream origin is read from server-only `MIA_RAG_AUTH_URL`, and the csy platform never stores password content or exposes the authentication-service address through `NEXT_PUBLIC_*`. ## csy——全智赛/backend

- `一键启动.bat`: local Windows launcher for the FastAPI service. It validates the copied virtual environment, falls back to the machine `python` executable when the venv points to a stale absolute path, reuses the venv site-packages directory, and supplies the development-only `TRACE_FINGERPRINT_KEY` required by the application lifespan.
- `backend/app/services/evaluation_service.py` and `backend/app/sandbox/composite.py`: evaluation creation validates the selected registered Agent (with the reference CorpMate fallback), passes its declared tool permissions into execution and the generic judge, and records permission denials as redacted trace events. Generic batches convert an unexpected per-case execution failure into `TEST_COMPLETED: ERROR` for every unfinished selected TestCase and still persist a degraded report, keeping the batch/report contract terminal and inspectable.
