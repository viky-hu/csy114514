# 登录页 Mock 登录与滚动蓝色扩展动画计划

## Summary

- 保留现有登录页的 React + SVG + GSAP 时间轴实现，不重写、不替换现有视觉系统。
- Mock 阶段取消账号、密码、注册申请的所有校验和真实接口约束：登录按钮可空字段直接成功，注册/申请接入按钮也直接成功。
- 登录成功后自动执行现有 Escape 收起动画；只有成功登录后的收起完成态，才启用第二屏滚动区域和底部鼠标滚轮提示。
- 第二屏高度为一个完整视口；滚动进度驱动蓝色色块从首次滚动时的鼠标 X 锚点向左右扩展，滚到第二屏终点时蓝色铺满全屏，首页文字随滚动上移离开视野。

## Key Changes

- `LoginForm`:
  - 移除 `authLogin/authRegister` 真实调用、空账号/空密码/确认密码限制、错误提示、申请等待提示。
  - 登录模式下点击“进入平台”直接调用 `onSignIn(false, account || "mock-evaluator")`。
  - 注册模式下点击“申请接入”也直接调用同一个成功登录回调。
  - 保留账号/密码输入框、密码显示切换、登录/注册切换视觉结构，保证现有 SVG 面板体验不塌。

- `LoginIntroWindow`:
  - 包装传给 `LoginForm` 的 `onSignIn`: 成功后设置本页内存登录态，然后调用现有 `closePanel()`，等同自动按下 Escape。
  - 增加 `isAuthenticated` 与 `isScrollReady` 状态：登录成功但收起动画未结束时不开放滚动；收起完成后才显示滚动提示并启用 200dvh 页面高度。
  - 手动 Escape 只收起面板，不设置登录态、不显示滚动提示、不开放第二屏。

- 滚动动画:
  - 使用现有 GSAP 体系并注册 `ScrollTrigger`，用真实页面滚动进度驱动动画，兼容滚轮、触控板、键盘和触屏。
  - 首次登录后滚动时锁定当前鼠标 X；后续滚动/逆滚动不再让蓝色条跟随鼠标。
  - 色块计算规则：`left = anchorX * (1 - progress)`，`right = anchorX + (viewportWidth - anchorX) * progress`，由此得到非对称左右扩展。
  - 首页 SVG 文案和 CTA 视觉组随滚动进度整体 `y = -viewportHeight * progress` 上移；滚到第二屏时首页内容离开视野，只剩蓝色全屏；回滚时内容回到第一页，并继续被蓝色色块触发反相。

- 样式与文档:
  - 在 `window-1-login.css` 中删除错误/等待提示框样式，新增登录后滚动态、第二屏占位、底部鼠标滚轮 SVG 提示样式。
  - 鼠标提示使用 `lucide-react` 的 SVG 图标或同等轻量 SVG，非文字说明，登录收起完成后显示，滚动开始后淡出。
  - 按 AGENTS 要求同步更新 `docs/architecture/modules-index.md` 和 `docs/architecture/extension-review-checklist.md`，记录登录页 mock 鉴权和登录后滚动扩展行为。

## Test Plan

- 运行 `corepack pnpm -C apps/main-platform type-check`。
- 运行 `corepack pnpm -C apps/main-platform build`。
- 手动验收：
  - 未登录时点击右下角 CTA，面板按现有动画展开。
  - 未登录时按 Escape，面板收起，但页面不可滚动、无鼠标滚轮提示。
  - 账号密码为空时点击“进入平台”，无报错，自动播放收起动画，收起完成后出现滚动提示。
  - 注册页点击“申请接入”，同样直接登录成功并自动收起。
  - 登录后首次向下滚动时锁定当时鼠标 X；滚动到第二屏终点时蓝色铺满全屏；逆滚回第一页时蓝色收回到同一 X 轴线。
  - 在不同鼠标 X 位置登录后滚动，左右扩展速度按左右距离不同而不同。
  - 视口 resize 后，第一页布局、色块宽度、第二屏终点仍正确。

## Assumptions

- Mock 登录态仅存在于当前 React 页面生命周期，刷新后回到未登录状态。
- 第二屏 MVP 不放业务内容，只验证蓝色色块滚动扩展动画。
- 不接入真实 BFF/auth，不写入 token，不使用 `NEXT_PUBLIC_MIA_RAG_AUTH_URL`。
- 不改动首页品牌文案、现有 SVG 主结构、已有展开/收起缓动曲线和核心视觉语言。

## 最终核对清单：用户原始需求要点

- 登录页优化必须基于现有初始界面，不重写、不替换现有 GSAP + SVG + 时间轴 + 动画体系。
- 现有首页的 React/SVG 视觉语言要被学习和延续，后续新界面也应按同一技术栈和实现方法推进。
- 右下角按钮触发展开逻辑保持：蓝色色块拉宽后弹出登录/注册 SVG 面板。
- Mock 阶段删除真实登录、注册、申请接入接口限制。
- 删除账号为空、密码为空、注册确认密码等阻断逻辑。
- 删除所有丑陋报错提示框和申请等待提示框。
- 账号密码都不填，也可以直接点击登录进入“已登录”状态。
- 注册/申请接入在 mock 阶段也应无约束成功。
- 登录成功后才自动触发现有 Escape 收起动画；未登录手动 Escape 只收起，不进入登录态。
- 登录成功收起后，页面回到初始首页视觉，但底部出现鼠标滚轮提示图案。
- 只有登录成功后，首页才从单页固定视口变成可滚动页面。
- 新增区域高度等于一个完整窗口高度，因此页面总高度为两个视口。
- 首次向下滚动时，记录当时鼠标所在的 X 坐标作为蓝色线/色块扩展中心轴。
- 滚动开始后，蓝色色块不再跟随鼠标，而是由滚动进度驱动。
- 蓝色色块左边界根据锚点到屏幕左侧距离等比例左移。
- 蓝色色块右边界根据锚点到屏幕右侧距离等比例右移。
- 左右扩展参数应独立计算，因为锚点通常不在屏幕正中心。
- 滚动到第二屏终点时，蓝色色块应刚好覆盖整个屏幕。
- 逆向滚动时，蓝色色块按同一锚点和同一路径收回。
- 滚动过程中蓝色色块仍应触发现有文字反相效果。
- 滚动到第二屏后，第一页文字因为随页面上移而离开视野，不需要额外出现在第二屏。
- 第二屏 MVP 暂不放业务内容，只验证蓝色扩展动画。
- 必要时参考 GSAP/SVG/ScrollTrigger 最佳实践，不能脱离现有成熟实现另起炉灶。

## 辅助提示词：后续实现时反复对齐

这是一个以 React + SVG + GSAP 时间轴为核心视觉语言的前端页面。当前登录页已有成熟的鼠标跟随色带、clipPath 文字反相、右下 CTA 展开、Escape 收起动画，这些是系统风格资产，不是临时代码。后续实现必须保留并学习它们。

Mock 登录阶段不追求真实鉴权，只追求“用户点击即可进入已登录状态”的体验闭环。登录成功后自动复用 Escape 收起动画，收起完成才解锁滚动。未登录状态下的 Escape 不能产生登录态。

登录后的新增重点不是普通第二屏内容，而是一次滚动驱动的 SVG 蓝色色块扩展实验：首次滚动锁定鼠标 X 轴，后续用滚动进度让蓝色条分别向左、向右扩展，直到第二视口终点覆盖全屏。滚动过程必须延续现有文字反相逻辑，保持页面技术风格统一。
