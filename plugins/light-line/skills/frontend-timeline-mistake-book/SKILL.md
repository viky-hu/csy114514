# 时间轴错题本

## 必须先画时间线

任何涉及窗口转场、全屏切换、聊天入场、输入框下移、菜单开合的改动，都先写阶段表，再写代码。阶段表至少包含触发、持续时间、受控元素、结束状态、输入锁定策略。

## 项目核心时间轴

- 登录窗口：页面加载自动开场绘制，结束为介绍态；用户一次交互触发白蓝反转、线条坍缩、内容切换，结束为登录表单态。
- 产品介绍：三个全屏 panel 按离散 index 切换，切换期间锁定滚轮和点击，轨道位移为整屏步进。
- 交互对话：画布完成后，模式切换行、消息流、输入发送区依次浮现。
- 菜单联动：画布和信息流同步左移，持续时间和 ease 保持一致。
- 初始态优化：提示语和居中输入框先出现，发送后输入框下移到原底部位置，再进入原有消息生成流程。

## 常见错题

### 错题 1：阶段结束状态没写清

错误做法：只写动画过程，不定义最后 DOM、颜色、透明度、点击域状态。

正确做法：每段 timeline 必须能回答“播完后页面处于什么稳定态”。

### 错题 2：滚轮连续触发导致越屏

错误做法：滚轮每触发一次都立即切 panel，不管上一次动画是否结束。

正确做法：切换动画期间锁定输入，每次只允许移动一个 panel，到首尾边界停止。

### 错题 3：新增动画挤坏原流程

错误做法：为了新增初始态输入框动画，改乱原有发送、气泡、流式输出时间轴。

正确做法：在原流程前插入新段，并整体右移后续事件，保持原有气泡与消息生成逻辑不变。

### 错题 4：FLIP 捕获时机反了

错误做法：状态更新后才捕获历史列表布局。

正确做法：`captureFlipState()` 必须在 `setConversations()` 之前调用，`useLayoutEffect` 执行 `Flip.from()`。

## 时间轴交付模板

- 触发：说明自动、滚轮、点击、发送、菜单开合等触发源。
- 阶段：列出每段的时间点、duration、ease、目标元素。
- 锁定：说明动画期间哪些输入被锁定。
- 结束：说明最终 index、颜色、布局、透明度、点击域。
- 回归：说明新建会话、模式切换、返回窗口、刷新页面是否恢复初始态。
